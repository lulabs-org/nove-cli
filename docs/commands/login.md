## `nove login`

Validate and securely store a Nove API Key

```
USAGE
  $ nove login [--api-key-stdin] [--json]

FLAGS
  --api-key-stdin  Read the API Key from stdin
  --json           Output a single JSON value to stdout

DESCRIPTION
  Validate and securely store a Nove API Key
```

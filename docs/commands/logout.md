## `nove logout`

Revoke OAuth access and remove the locally stored credential

```
USAGE
  $ nove logout [--json] [--local-only]

FLAGS
  --json        Output a single JSON value to stdout
  --local-only  Remove local OAuth state without contacting the API

DESCRIPTION
  Revoke OAuth access and remove the locally stored credential
```

`nove auth`
===========

Inspect local authentication state

* [`nove auth status`](#nove-auth-status)

## `nove auth status`

Show authentication status without exposing credentials

```
USAGE
  $ nove auth status [--json]

FLAGS
  --json  Output a single JSON value to stdout

DESCRIPTION
  Show authentication status without exposing credentials
```

_See code: [src/commands/auth/status.ts](https://github.com/lulabs-org/nove-cli/blob/v1.0.4/src/commands/auth/status.ts)_

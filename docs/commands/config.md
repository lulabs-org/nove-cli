`nove config`

* [`nove config set KEY VALUE`](#nove-config-set-key-value)

## `nove config set KEY VALUE`

Set a configuration value

```
USAGE
  $ nove config set KEY VALUE [--json]

ARGUMENTS
  KEY    Configuration key (e.g., base-url)
  VALUE  Configuration value

FLAGS
  --json  Output a single JSON value to stdout

DESCRIPTION
  Set a configuration value
```

_See code: [src/commands/config/set.ts](https://github.com/lulabs-org/nove-cli/blob/v1.3.0/src/commands/config/set.ts)_
